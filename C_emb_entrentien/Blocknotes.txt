    ComM (Communication Manager) : il décide si on communique ou pas

    Une application (ou le Dcm) dit : « j’ai besoin de communiquer »
    ComM gère cette demande par réseau (un canal par réseau)
    3 modes : FULL (émission + réception), SILENT (réception seule), NO (rien)
    Il ne touche pas au CAN directement : il donne l’ordre à CanSM

    CanSM (CAN State Manager) : il exécute l’ordre sur le réseau CAN

    Il met le contrôleur et le transceiver dans le bon mode (démarré, arrêté, veille)
    Il gère le bus-off : quand le contrôleur a trop d’erreurs, il se coupe du bus. CanSM le détecte, attend, puis relance le contrôleur (récupération bus-off)
    Il remonte l’état à ComM

    CanTrcv (CAN Transceiver Driver) : il pilote la puce transceiver

    Il change son mode : Normal, Standby, Sleep
    Il gère le réveil par le bus (wake-up)
    Il se trouve dans la couche ECU Abstraction, car le transceiver est sur la carte, pas dans le micro
